# ntsc-rs website

This is the static site for [ntsc-rs](https://github.com/ntsc-rs/ntsc-rs). It's built with [Eleventy](https://www.11ty.dev/).

## Building

Install dependencies:

```bash
npm install
```

Build the site:

```bash
npm run build
```

The output will be in the `_site/` directory.

## Development

Run a local development server with live reload:

```bash
npm run dev
```

The site will be available at `http://localhost:8080`.
